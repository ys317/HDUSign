# HDUSign v2.4.0

本版增加多账号、连堂课自动续接和多门课程预约，保留自动签到、签到页预热及企业微信通知。感谢 sheeppp1 提供的功能改进。

## 更新内容

- **多账号**：最多同时监听五个账号，课程、预约、登录态、签到浏览器和记录分别保存。切换查看不会停止其他账号的任务，密码与机器人地址使用 Windows DPAPI 加密。
- **连堂课**：根据课表核验并合并两节／三节连堂，提前两分钟尝试监听，末节下课后延长两分钟；第三节切换时清除未确认转写，避免把断点两侧数字拼成签到码。
- **多门预约**：同一账号可预约多门不重叠课程，按时间依次启动；查看其他课程不取消原预约。修复保存失败后预约可能在重启时重新出现的问题。
- **课程通知**：机器人按课程绑定，监听时间不重叠时可复用；通知携带账号姓名和课程名，修改默认机器人不会改变已有预约。
- **自动签到**：保留浏览器预热、位置设置和签到登录；每个账号的签到子进程与凭据隔离。验证码无法自动处理时提示本人接手，并以平台本次签到响应为准。
- **轨迹处理**：保留可关闭的本地轨迹增强，修正人工接手、样本归档、事件时间与坐标边界；不保证验证码通过率。实验性的 webdriver 标志调整未加入生产配置。
- **诊断与登录**：默认保留启动诊断，最多录制三分钟启动音频，可在设置中关闭；优化日志刷新与登录凭据后台验证。
- **运行与打包**：桌面统一使用后台直播音频，旧配置自动兼容；命令行电脑声音采集保留。修复源码子进程入口以及完整／增量发行包的 QML 路径兼容。

## 下载与升级

下载 `HDUSign-v2.4.0-win64.zip`，完整解压后运行 `HDUSign.exe`。支持 Windows 10 / 11 x64，内置 Python、浏览器、识别模型及音频组件，请保留 `_internal/` 与 `models/`。

升级前关闭旧版，将新版解压到新目录。按 [升级说明](https://github.com/ys317/EchoSign#升级) 保留旧配置与登录态；使用过多账号版本时，还应保留 `accounts.json`、`webhooks.json` 和整个 `account_data/`。加密数据与当前 Windows 用户绑定，跨电脑或用户迁移可能需要重新登录及配置机器人。

预约需要软件持续运行，关闭或睡眠期间无法监听。每个账号同一时间只监听一门课程。诊断录音和日志不会自动清理，可从设置打开对应账号目录。

发行验证覆盖离线功能回归，以及解压后的界面、浏览器、识别模型和音频组件自检；不代表已完成真实多账号课堂、跨节、验证码或企业微信投递验收。请以平台记录为准。

发行包同时提供 `SHA256SUMS.txt` 与 FFmpeg 组件的对应源码归档。
