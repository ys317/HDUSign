# HDUSign v2.4.1

本版新增 **Linux x64 便携版**（`.tar.gz`）构建与发布流程，并保留 Windows x64 便携版及多账号、连堂课、多门预约、自动签到与企业微信通知功能。

## 更新内容

- **Linux x64 便携版**：新增 `HDUSign-v2.4.1-linux-x64.tar.gz`，内置 Python 运行环境、PySide6 / Qt Quick、Playwright Chromium、语音与语义模型及精简音频 FFmpeg，支持通过 `./HDUSign` 启动，并附带可选的 `./install-desktop.sh` 桌面菜单安装脚本。
- **跨平台账号与进程隔离**：Linux 下使用当前用户目录 `~/.config/HDUSign/vault.key`（可通过 `HDUSIGN_VAULT_KEY_PATH` 覆盖）保护本地账号密码与机器人地址；多账号工作进程与签到浏览器使用独立进程组管理与清理。
- **Linux 精简音频组件**：提供 `tools/ffmpeg-build/build_linux.sh` 与 GitHub Actions 工作流，从官方 FFmpeg 8.1.2 源码编译仅含音频解码和 GnuTLS 验证（配合 `certifi` 证书库）的 LGPL 组件，并随发布附带对应源码归档 `ffmpeg-8.1.2-hdusign-audio-linux64-source.tar.xz`。
- **预约排序、玻璃外观与提醒关键词**：合入预约账号优先／最近使用排序与预约底色、全局桌面透视玻璃（`appearance.json`，Windows 11 22H2+ 支持原生透视，其余环境及 Linux 自动回退普通外观），以及扩充的默认强提醒关键词（`上课啦`、`打开上课啦`、`手机打开`、`打开手机`、`钉钉`、`点到`）。
- **登录表单兼容**：优化统一身份认证登录页输入框识别，提升不同页面结构下的自动填表兼容性。

## 下载与使用

- **Windows 10 / 11 x64**：下载 `HDUSign-v2.4.1-win64.zip`，完整解压后运行 `HDUSign.exe`。
- **Linux x64**（Ubuntu 22.04+ 等 glibc >= 2.35 桌面环境）：下载 `HDUSign-v2.4.1-linux-x64.tar.gz`，执行：

  ```bash
  tar -xzf HDUSign-v2.4.1-linux-x64.tar.gz
  cd HDUSign
  ./HDUSign
  ```

  如需添加桌面应用菜单快捷方式，可运行 `./install-desktop.sh`。若在部分发行版缺少系统共享库（如 `libpulse0`、`libgnutls30`、X11/OpenGL 或 Playwright 依赖），可按使用环境的提示补齐对应系统包。

发行包同时提供对应平台的校验文件（`SHA256SUMS.txt` / `SHA256SUMS-linux-x64.txt`）及 FFmpeg 组件对应源码归档。
