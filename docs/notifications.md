# 企业微信通知

从课程列表选课并启动监听后，签到提示、签到码、自动签到结果和人工验证通知使用同一个任务的通知路由，并带姓名与课程。姓名来自学校已验证的当前用户接口；课程取启动任务的快照，三节课切换链接不改变归属。

旧登录资料没有姓名时，可使用同一登录态补查。账号标识不匹配、登录失效或读取失败时，不使用其他账号姓名；手填地址未匹配课程时显示未选择课程。切换界面、修改默认机器人不会改变正在运行任务的归属。

在设置中填写机器人名称与 Webhook，点击“测试推送并保存机器人”。该操作会发送真实测试消息；只有请求成功且企业微信返回 `errcode=0` 才保存。Webhooks 可作为共用默认或账号默认，预约时再固定到课程。监听时间冲突规则见[每课机器人](reservation-webhooks.md)。

Webhook 可留空，此时只保留本地提醒。测试或监控失败时，先核对活动记录、机器人地址和课程绑定，再决定是否重新测试。
