# 功能索引

本文描述当前源码，入口与常用操作见 [README](../README.md) 和[使用指南](usage.md)。本次合并保留自动签到；贡献分支中移除签到的行为与个人版本交付记录不适用于当前源码。

| 功能 | 当前行为 | 详细说明 |
| --- | --- | --- |
| 连堂课 | 元数据核验后合并两节／三节课；两节复用首节链接，第三节切到已确认的对应链接；切换时清除未确认转写 | [连堂课](continuous-lessons.md) |
| 监听时间 | 每节提前两分钟尝试，末节下课后两分钟停止；未开播每六秒重试，受时间窗口和取消信号限制 | [连堂课](continuous-lessons.md) |
| 多门预约 | 每账号可预约多门，按时间依次运行；查看其他课程不取消预约，同账号不并行监听多门课 | [预约](multiple-reservations.md) |
| 多账号 | 桌面仅用后台直播音频，最多同时监听五个账号；配置、会话、浏览器、轨迹库、日志和通知按账号隔离 | [多账号](multi-account.md) |
| 账号保存 | 成功登录且选择记住后保存加密密码；切换显示不停止其他任务，删除运行中账号前需停止 | [账号管理](accounts.md) |
| 通知机器人 | 测试成功后保存，可设共用或账号默认；每门预约固定绑定，监听时间不重叠时可复用 | [每课机器人](reservation-webhooks.md) |
| 诊断 | 默认开启，可关闭；最多保存每次监听的三分钟启动音频，日志按账号持久保存 | [诊断](diagnostics.md) |
| 登录验证 | 登录页不发身份探测；取得 JWT 后在浏览器上下文后台验证；失败不覆盖旧会话 | [登录验证](login-auth-fix.md) |
| 自动签到 | 可关闭；启用时预热页面、输入确认码并等待平台结果；无法自动处理的验证由本人完成 | [使用指南](usage.md#转写与签到码) |
| 提醒关键词 | 默认新增“上课啦”“打开上课啦”“手机打开”“打开手机”“钉钉”“点到”；包含任意一项即高优先级提醒，时间／节点中的“点到”也会命中；已有用户配置需在设置中追加 | [常用设置](../README.md#提醒关键词与全局外观) |
| 账号排序 | 有预约账号优先，两组内按最近使用时间降序；预约底色略深，切换查看不停止其他账号 | [多账号](multi-account.md) |
| 全局玻璃 | 可关闭、可调透视／着色／高光，单独保存并对所有账号生效；系统不支持时回退普通外观 | [外观](appearance.md) |

软件只根据可靠的课表元数据续接，不猜测手填地址、缺失节次或四节以上课程。同账号预约按不重叠课程顺序运行；睡眠或关闭软件期间无法采集。

离线测试不能证明真实课堂、验证码或多账号同时取流已全部验证。登录表单会尝试自动填写和提交，验证码仍由本人处理；当前实现不承诺所有平台页面都没有原生认证弹窗。
