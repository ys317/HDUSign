# 账号管理 v2.0.4

> 版本范围：本文记录 v2.0.4。2026-10-22 源码修改已随 v2.3.2 交付，已移除签到专用登录与子进程；直播登录保留，旧签到浏览器目录仍在删除账号时清理。当前多账号隔离及规则见[功能规则](功能规则.md)与[多账号](multi-account.md)。“下次启动不自动提交”仅指启动不自行发起登录；用户发起登录后的 SSO 辅助仍会尝试提交，与“由本人点击登录”的要求存在待修正差异。

运行 `HDUSign-continuous-v2.0.4.exe`，在设置页选择已保存账号，或点击“新账号”。
默认开启“记住此账号”：点击“登录并读取课程”，成功后自动保存并更新密码。
失败不覆盖已经验证的密码。修改学号会新增账号，旧账号可单独删除。
下次启动只自动填入上次记住的账号，不自动提交登录。
“单独登录直播账号”属于手动浏览器登录，软件无法确认输入的密码，因此不加入账号列表。

取消“记住此账号”后，本次成功登录不新增或更新账号记录，下一次启动不自动填入。
原来已经保存的账号仍可从列表选择；需要移除时使用“删除账号”。
删除需要确认，同时清理对应签到浏览器目录及匹配的直播登录状态。
正在运行任务时不能切换或删除账号。若浏览器目录被占用，关闭窗口后重试。

密码在 accounts.json 中由当前 Windows 用户的 DPAPI 加密，复制到其他 Windows
账号或电脑无法直接解密。旧 secrets_local.json 明文密码首次读取后迁移为加密字段，
在成功登录后改由账号库管理。临时凭据通过加密的进程环境传给签到子进程，不写入磁盘。
本机当前 Windows 用户仍可解密；这不防护已控制当前用户环境的程序。

新版界面文件位于 `_internal/qml-2.0.4`，保留整个发行目录。
旧 exe 不理解新加密账号格式，建议使用新版；不要用旧版重新保存明文密码。
