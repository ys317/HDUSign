# 账号管理

在设置中选择已保存账号，或点击“新账号”填写学号密码后登录。选择记住且登录成功后，账号库才保存或更新密码；失败和取消不会覆盖已验证的账号资料。修改学号视为另一个账号，旧账号可单独删除。

取消“记住此账号”后，本次凭据只在当前会话使用，已有的账号记录不会自动删除。下次启动可填入已保存账号，用户发起登录后会尝试自动填写和提交表单；需要验证码时在浏览器完成。“单独登录直播账号”使用手动浏览器流程，不自动记住无法确认的密码。

多账号界面可以切换查看，不会停止其他账号的任务。删除账号前须停止该账号任务；确认删除会清理其配置、预约、登录会话、签到浏览器和日志，不影响其他账号。浏览器目录被占用时先关闭对应浏览器再重试。

密码保存在 `accounts.json`，由当前 Windows 用户的 DPAPI 加密。旧 `secrets_local.json` 的明文密码可迁移为加密字段，成功登录后由账号库管理。未记住的凭据通过加密进程环境传给对应账号的子进程，不作为命令行参数或明文配置保存。

加密资料与 Windows 用户绑定，复制到另一电脑或另一用户下可能无法解密。当前 Windows 用户仍能解密，直播会话、浏览器资料及旧配置也应妥善保管。数据目录及隔离方式见[多账号](multi-account.md)。
